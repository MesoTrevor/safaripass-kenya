# Safari Pass roadmap

- [ ] Build the approved public website and passenger demo dashboard; make sample flows interactive and explicitly non-live.
- [ ] Expand the passenger experience: Lovable Cloud, sign-in and profiles, wallet ledger, subscription/credit batches, journeys, travel pass, and notifications.
- [ ] Build operator/SACCO and conductor experiences with organization-scoped data and verification workflows.
- [ ] Build administrator tools, route/vehicle approval, settlements, reconciliation, audit trails, and reporting.
- [ ] Integrate configured payment providers and verified callbacks; do not simulate successful payments.
- [ ] Document operational setup, security boundaries, environment configuration, and release limitations.
